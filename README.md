# Web Development Internship - Task 2: Intermediate HTML, CSS & JavaScript

**ApexPlanet Software Pvt. Ltd. | HTML, CSS & JavaScript**

## Features
1. **Contact form** (HTML + CSS): text, email, dropdown, textarea and submit button.
2. **Form validation** (JavaScript): required fields, minimum lengths and email format check, with error messages.
3. **Responsive layout**: Flexbox navigation, CSS Grid content area, and media queries for tablet and mobile.
4. **Dynamic to-do list** (DOM manipulation): add tasks, mark them done, delete them, clear all.

## Project Structure
```
.

```

Open `index.html` in any browser. No installation needed.
